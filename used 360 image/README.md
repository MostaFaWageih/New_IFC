# Used 360 images on the coordinated model (structure + architecture)

_Positions and headings are AI estimates (no GPS). Generated by `Video_360_Analysis/vfinal.py`._

One folder per scene (10 photos, one per position). P01 and P02 were shot as 3-exposure HDR brackets; only the normal exposure (EV 0) is kept. Each folder holds the real 360, the combined model 360 at the same spot and heading, a real / model / blend compare sheet and a README with the location.

The video frames are in [`../360 image cut from video`](../360%20image%20cut%20from%20video/README.md).

## The coordinated model

- Structure: `2-1319-HAC-MOD-SSC-00-GL-BS-01_detached--STRUCTRE-MODEL_detached.ifc` (IFC4X3 in header, read as IFC4X3_ADD2), georeferenced by IfcMapConversion #29 to EPSG:22992.
- Architecture: `1-1319-HAC-MOD-AAR-00-GL-BS-01_detached_detached.ifc`. No georeference of its own; it shares the structural project coordinates (same storey levels and plan extents, 453 structural columns with an architectural element centred within 0.5 m), so one coordinate set is valid in both files and in a federated (Navisworks) model of the two.
- **IFC X, Y, Z (mm)**: project coordinates in both IFC files (X east, Y north, Z up). Site metres used in the analysis = IFC m minus (-343771, -402380).
- **Easting, Northing**: EPSG:22992, from IfcMapConversion (E0 1031135.267, N0 1208737.217). **Lat, lon**: WGS84. **Heading**: compass bearing of the image centre, from the sun.
- **Camera**: eye at the image spot (1.5 m above the floor), target 10 m along the heading, up +Z, 90 deg per cube face. Enter eye and target in Revit/Navisworks to get the same view.
- Combined = both meshes in one scene. Sand = architecture; orange columns, grey walls, blue slabs, green beams = structure. Design view: everything within 80 m that starts up to 4 m above the eye; slabs, beams and coverings above the camera's feet hidden.
